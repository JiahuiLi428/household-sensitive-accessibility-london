# Household-sensitive accessibility in London

This repository contains source and processed data, analysis code, robustness
extensions, and figures for a London 15-minute-city accessibility study.

## Manuscript status

The dissertation is still being revised following supervisory feedback.
Working DOCX files are intentionally excluded from version control. The final
submitted manuscript may be added here after submission.

## Main analysis

Run commands from the repository root. The default pipeline uses the stored R5r
travel-time tables and runs steps 02-12:

```powershell
Rscript scripts/model/run_pipeline.R
```

To rebuild the R5 network and rerun routing as well:

```powershell
Rscript scripts/model/run_pipeline.R --include-r5r
```

The latter requires the large OSM and GTFS inputs described in
`data/LARGE_FILES.md`.

Additional reported checks are produced by:

```powershell
Rscript scripts/examiner_sensitivity_checks.R
Rscript scripts/additional_robustness_20260806.R
```

## Data provenance and reproducibility

- Source URLs and output locations: `data/download_manifest.json`
- Input checksums: `data/CHECKSUMS.sha256`
- Main configuration: `scripts/model/00_config.R`
- Recorded environment: R 4.5.1, r5r 2.4.0, sf 1.1.1, spdep 1.4.1,
  data.table 1.18.4, ggplot2 4.0.3, readxl 1.4.5 and arrow 24.0.0;
  stored R5 version 7.5.1.

The final figures are generated by the retained R/Python figure workflows. An
older optional ArcMap branch and its geodatabase are retained only in the local
archive and are not required by the final analytical pipeline.

The project does not contain a complete `renv` lockfile, so exact binary-level
reproduction across machines is not guaranteed. Seeds, parameters and stored
analysis outputs are retained for procedural replication.
